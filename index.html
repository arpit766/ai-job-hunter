Open source · MCP · Review-first apply

AI Job Hunter

Discover roles, score fit with rules + evidence, draft applications, and submit only after explicit approval.

Repository

Full stack: Next.js dashboard, PostgreSQL + Prisma, Redis + BullMQ worker, TypeScript MCP server for Cursor.

View on GitHub Setup guide

Run locally (dashboard)

docker compose up -d
npm install
npx prisma db push
npm run db:seed
npm run dev:web

Dashboard: http://localhost:3100 — requires Postgres/Redis from Docker Compose.

MCP tools

  • search_jobs, score_job_match, draft_application
  • approve_application, submit_application (mock provider)
  • generate_daily_report, track_application
